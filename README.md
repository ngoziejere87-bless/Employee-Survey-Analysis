# Employee Survey Analysis

## Project Overview
This project analyses employee survey responses using Microsoft Power BI. The aim is to understand employee satisfaction, identify workplace concerns and compare feedback across departments.

## Project Objectives
- Examine overall employee satisfaction.
- Analyse employee feedback and workplace experiences.
- Compare negative responses across departments.
- Identify areas where management can improve employee engagement.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- GitHub

## Dataset Overview
The dataset contains **14,725 survey records**, consisting of:
- Complete responses: 14,590
- Incomplete responses: 135

## Dashboard Pages

### Page 1: Main Employee Survey Dashboard
This page provides an overview of the survey, including response totals, employee satisfaction, recognition, workplace friendship and interactive filters.

### Page 2: Detailed Departmental Analysis
This page compares negative employee responses across departments to identify areas that may require management attention.

## Key Findings
- Overall job satisfaction was approximately 75.73%.
- Negative feedback varied across departments.
- The Sheriff's Department recorded the highest negative response share in the departmental comparison.
- The departmental analysis highlights areas where further investigation and improvement may be needed.

## Recommendations
- Investigate the reasons behind negative employee feedback.
- Develop targeted improvement plans for departments with higher negative response shares.
- Improve employee recognition and engagement.
- Conduct regular employee surveys to monitor progress.
